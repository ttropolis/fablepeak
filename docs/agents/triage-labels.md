# Triage Labels

The engineering skills use five canonical triage roles. This file maps those roles to the GitHub labels used by this repository.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `MattPocok:needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `MattPocok:needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `MattPocok:ready-for-agent` | Fully specified and ready for an AFK agent |
| `ready-for-human` | `MattPocok:ready-for-human` | Requires human implementation |
| `wontfix` | `MattPocok:wontfix` | Will not be actioned |

When a skill refers to a canonical role, use its corresponding GitHub label from this table.
