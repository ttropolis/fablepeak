# FablePeak Meta production review

FablePeak is a Tech Provider-style application: customers connect their own
Facebook Pages and Instagram professional accounts so FablePeak can publish on
their behalf. Customer accounts do not need developer roles after Meta approves
the app and it is Live.

## Current diagnosis

The Instagram message `Insufficient Developer Role` is generated by Meta before
FablePeak's OAuth callback runs. The Meta app is Unpublished and currently has
no tester accounts, so an unrelated customer account is correctly rejected in
development mode. This is not an Instagram password or Supabase callback error.

For a temporary development-only test, add the tester's Meta developer identity
to the app and have that person accept the invitation before retrying with the
same Instagram professional account. This is not customer onboarding.

The permanent fix is:

1. Classify FablePeak as a Meta Tech Provider.
2. Complete Meta business verification and access verification.
3. Add only the permissions below to App Review.
4. Supply the requested reviewer instructions, credentials and recordings.
5. Obtain Advanced Access and publish the app Live.
6. Validate with an unrelated Business account and an unrelated Creator
   account before inviting customers.

Meta marks Tech Provider classification as an irreversible decision. Confirm
the business entity and portfolio that will own the production integration
before continuing that onboarding flow.

## Direct Instagram Login permissions

- `instagram_business_basic` — read the connected professional account's ID,
  username, name and profile picture so the user can verify the selected account.
- `instagram_business_content_publish` — publish a customer-created image or
  video only after the customer explicitly selects Instagram and publishes or
  schedules the post.

Do not request messaging, comments, ads, public-content, branded-content or
insights permissions for the current product.

## Reviewer recording

Use a developer-owned Instagram Business or Creator profile and a non-sensitive
test image/video. Record in English with the full browser address bar visible.

1. Sign in to the production FablePeak site and open a workspace.
2. Open Connections and choose Connect Instagram.
3. Sign in to the professional Instagram profile and approve both permissions.
4. Return to FablePeak and show the exact connected username/avatar.
5. Create a media post, select only Instagram and publish it.
6. Show the successful platform result in FablePeak.
7. Open the Instagram profile and show the newly published media.
8. Return to Connections and show the disconnect action.

The recording must not expose passwords, app secrets, access tokens or private
customer information.

## Reviewer explanation

FablePeak uses `instagram_business_basic` after a user explicitly connects an
Instagram Business or Creator account. The returned account ID, username, name
and profile picture are displayed inside that user's workspace so the user can
verify the connected destination. FablePeak uses
`instagram_business_content_publish` only when that user creates or schedules a
post containing media and selects Instagram as a destination. The app then
creates and publishes the media container to that same connected professional
account. The permissions are not used for unrelated accounts, credentials are
stored server-side and encrypted, and the user can disconnect the account.

## Launch gate

- Business portfolio and legal entity chosen for permanent ownership.
- Business verification complete.
- Access verification complete.
- Both permissions approved for Advanced Access.
- App is Live, not merely Unpublished/Development.
- Business and Creator unrelated-account tests both pass.
- Facebook Page permissions are separately approved before Facebook general
  onboarding is enabled.
